# Qing-Emulator
大清模拟器

## 游戏简介
这是一个基于C++开发的大清帝国历史模拟游戏。玩家扮演大清帝国的统治者，在列强环伺的困境下，通过外交、军事、经济、科技等多种手段保卫国家领土，最终实现中兴大业。

## 游戏目标
- **胜利条件**：收复所有18个省份
- **失败条件**：控制省份少于8个

## 游戏特色

### 1. 经济系统
- 每个省份产生收入，收入数额取决于省份经济价值
- 使用国库资金招募军队、研究科技、进行外交等
- 每回合自动收取控制省份的税收

### 2. 军事系统
- **招募士兵**：花费银两招募新军
- **派遣驻军**：向省份派遣军队加强防御
- **防御工事**：建造防御设施提升省份防御力（最高5级）
- **将领系统**：招募历史名将（如左宗棠、李鸿章、曾国藩等）提升战斗力

### 3. 科技系统
研究洋务运动相关科技：
- **洋务运动**：学习西方技术，提升工业能力
- **新式陆军**：建立现代化陆军
- **北洋水师**：建立现代海军
- **铁路建设**：修建铁路网络
- **电报系统**：建立通讯网络
- **维新变法**：进行政治改革

### 4. 外交系统
- **贿赂列强**：改善与某个列强的关系
- **签订条约**：通过外交手段避免战争
- 外交关系影响列强的侵略性

### 5. 谍报系统
- **升级谍报网络**：提升情报能力（最高5级）
- **刺探敌情**：获取敌方省份的军力信息
- **破坏行动**：削弱敌方省份的军事力量

### 6. 改革系统
- 推进改革提升国家整体实力
- 改革可以提升军事科技和省份稳定度
- 改革进度最高100%

### 7. 事件系统
随机历史事件可能影响游戏进程：
- 太平天国起义
- 义和团运动
- 洋务运动成果
- 丰收之年
- 自然灾害

## 游戏机制

### 省份属性
每个省份具有以下属性：
- **控制者**：当前控制该省份的势力
- **驻军数量**：省份的军事力量
- **收入**：每回合产生的税收
- **防御等级**：防御工事等级（0-5）
- **稳定度**：省份稳定程度（0-100）

### 战斗系统
列强进攻时，防御力 = 驻军 + 防御工事加成 + 将领加成 + 科技加成
- 攻击力 > 防御力：省份被占领
- 攻击力 ≤ 防御力：防御成功，但会损失部分军队

### 列强势力
游戏中包含五个列强：
- 英国
- 法国
- 俄国
- 日本
- 德国

列强每回合会自动行动，可能进攻清国省份或加强自己的控制区。

## 编译与运行

### 编译
```bash
mkdir build
cd build
cmake ..
make
```

### 运行
```bash
./QingEmulator
```

## 游戏界面说明

### 主菜单选项
1. 派遣驻军 - 向指定省份增派军队
2. 招募士兵 - 在直隶招募新军
3. 研究科技 - 选择科技进行研究
4. 招募将领 - 招募历史名将
5. 外交行动 - 进行外交活动
6. 谍报活动 - 进行情报工作
7. 建造防御工事 - 加强省份防御
8. 推进改革 - 推动国家改革
9. 结束回合 - 结束当前回合，进入列强回合
0. 退出游戏 - 退出游戏

## 游戏策略建议
1. **优先发展经济**：富裕省份如江苏、广东产生大量收入，务必保护
2. **科技为先**：尽早研究军事科技提升战斗力
3. **外交缓冲**：适时使用外交手段缓解压力
4. **防御要塞**：在关键省份建造防御工事
5. **情报先行**：升级谍报网络掌握敌情
6. **改革强国**：持续推进改革提升综合国力

## 开发信息
- 语言：C++
- 构建系统：CMake
- 最低CMake版本：3.10
- C++标准：C++14

## 历史背景
游戏背景设定在晚清时期（19世纪末至20世纪初），此时大清帝国面临内忧外患，列强虎视眈眈。玩家需要在这个动荡的时代力挽狂澜，保卫国家主权和领土完整。
